# Theming Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** smile eyes corporate design as default theme, a Neutral preset, and four overridable base colours in the settings with contrast warnings.

**Architecture:** A pure module `app/services/theme.py` turns four base colours (+ preset extras) into light/dark CSS token maps and WCAG warnings. `static/style.css` defaults equal the smile eyes output (a test keeps them in sync). Stored overrides are rendered into an inline `<style id="theme">` after the stylesheet. The PDF takes the same colours.

**Tech Stack:** FastAPI, Jinja2, plain CSS custom properties, vanilla JS, PostgreSQL `app_settings`, ReportLab, pytest/unittest.

**Spec:** `docs/superpowers/specs/2026-10-11-theming-design.md`

## Global Constraints

- Brand palette (exact): Dark Blue `#141450`, Street Blue `#4A7EB5`, Neon Yellow `#FFFF00`, Beige `#EFE7DB`, Light Beige `#F8F5F2`, Light Sage `#D8DDCE`.
- Default preset for all installations: `smile_eyes`; second preset `neutral` = today's colours.
- Overridable base colours: primary, accent, background, running. Settings keys `theme_preset`, `theme_primary`, `theme_accent`, `theme_background`, `theme_running` (empty = preset value).
- Neon Yellow is never used as a text colour; on yellow the text is Dark Blue.
- Contrast thresholds (WCAG 2.x): ink on background ≥ 4.5, accent ink on accent ≥ 4.5, header text on primary ≥ 4.5, running on background ≥ 3.0. Violations warn, saving is still allowed.
- Font: Instrument Sans (SIL OFL 1.1), self-hosted in `static/fonts/`, `OFL.txt` alongside; no runtime request to Google. Brand wordmark keeps `--font-brand`.
- Status colours (`--ok`, `--warn`, `--critical`, `--unknown`, `--spark-*`) are not derived from the theme.
- All user-facing strings via i18n (DE + EN).

## Review Focus

- Hex input with uppercase, 3-digit shorthand or whitespace (`" #fff "`) — accepted and normalised to `#ffffff`.
- Invalid hex (`"red"`, `"#12345"`) — rejected with a field error, no setting changed.
- Unknown/garbage `theme_preset` in the DB — page renders with smile eyes, no 500.
- Accent set to white with primary text white → accent ink falls back to the darker of black/primary, never white on white.
- Theme rendering raising for any reason — page still renders (stylesheet defaults), error logged.

```python
"""Colour theme: four base colours → light/dark CSS tokens, WCAG checks."""

from __future__ import annotations

import re
from dataclasses import dataclass

_HEX_RE = re.compile(r"^#?([0-9a-f]{3}|[0-9a-f]{6})$")
WHITE, BLACK = "#ffffff", "#000000"


def normalize_hex(value: str | None) -> str | None:
    match = _HEX_RE.match((value or "").strip().lower())
    if not match:
        return None
    digits = match.group(1)
    if len(digits) == 3:
        digits = "".join(c * 2 for c in digits)
    return f"#{digits}"


def _rgb(hex_color: str) -> tuple[int, int, int]:
    h = hex_color.lstrip("#")
    return int(h[0:2], 16), int(h[2:4], 16), int(h[4:6], 16)


def _hex(rgb: tuple[float, float, float]) -> str:
    return "#" + "".join(f"{max(0, min(255, round(c))):02x}" for c in rgb)


def mix(a: str, b: str, weight_b: float) -> str:
    """sRGB mix: weight_b of `b` into `a`."""
    ra, rb = _rgb(a), _rgb(b)
    return _hex(tuple(x * (1 - weight_b) + y * weight_b for x, y in zip(ra, rb, strict=True)))


def rgba(hex_color: str, alpha: float) -> str:
    r, g, b = _rgb(hex_color)
    return f"rgba({r}, {g}, {b}, {alpha})"


def _luminance(hex_color: str) -> float:
    def channel(c: int) -> float:
        s = c / 255
        return s / 12.92 if s <= 0.03928 else ((s + 0.055) / 1.055) ** 2.4

    r, g, b = (channel(c) for c in _rgb(hex_color))
    return 0.2126 * r + 0.7152 * g + 0.0722 * b


def contrast_ratio(a: str, b: str) -> float:
    la, lb = sorted((_luminance(a), _luminance(b)), reverse=True)
    return (la + 0.05) / (lb + 0.05)


def best_ink(surface: str, *candidates: str) -> str:
    """First candidate with ≥ 4.5:1 on `surface`, else the best of black/white."""
    for ink in candidates:
        if contrast_ratio(ink, surface) >= 4.5:
            return ink
    return max((BLACK, WHITE), key=lambda ink: contrast_ratio(ink, surface))


@dataclass(frozen=True)
class BaseColors:
    primary: str
    accent: str
    background: str
    running: str


@dataclass(frozen=True)
class Preset:
    base: BaseColors
    line: str  # borders / dividers (not overridable)
    sage: str  # calm info surfaces (not overridable)


PRESETS: dict[str, Preset] = {
    "smile_eyes": Preset(
        base=BaseColors(primary="#141450", accent="#ffff00", background="#f8f5f2", running="#4a7eb5"),
        line="#efe7db",
        sage="#d8ddce",
    ),
    "neutral": Preset(
        base=BaseColors(primary="#141450", accent="#141450", background="#f2f5fa", running="#1f5fbf"),
        line="#d9e1ec",
        sage="#edf1f7",
    ),
}
DEFAULT_PRESET = "smile_eyes"
BASE_KEYS = ("primary", "accent", "background", "running")


def resolve(preset_name: str | None, overrides: dict[str, str]) -> tuple[Preset, BaseColors]:
    preset = PRESETS.get(preset_name or "", PRESETS[DEFAULT_PRESET])
    values = {key: normalize_hex(overrides.get(key)) or getattr(preset.base, key) for key in BASE_KEYS}
    return preset, BaseColors(**values)


def derive_tokens(preset: Preset, base: BaseColors) -> dict[str, dict[str, str]]:
    p, a, bg, run = base.primary, base.accent, base.background, base.running
    accent_ink = best_ink(a, p)
    header_text = best_ink(p, "#f6f7ff")
    light = {
        "--bg": bg,
        "--panel": WHITE,
        "--panel-alt": mix(bg, WHITE, 0.5),
        "--ink": p,
        "--muted": mix(p, bg, 0.42),
        "--accent": p,
        "--line": preset.line,
        "--chip": mix(p, WHITE, 0.94),
        "--chip-border": mix(p, WHITE, 0.82),
        "--header-bg": p,
        "--header-border": mix(p, WHITE, 0.15),
        "--header-link": header_text,
        "--header-link-muted": mix(header_text, p, 0.25),
        "--btn-bg": p,
        "--btn-text": header_text,
        "--btn-border": mix(p, WHITE, 0.22),
        "--accent-fill": a,
        "--accent-ink": accent_ink,
        "--running": run,
        "--running-soft": rgba(run, 0.10),
        "--running-fill": rgba(run, 0.20),
        "--sage": preset.sage,
        "--sage-ink": p,
    }
    dark_bg = mix(p, BLACK, 0.45)
    dark_panel = mix(p, BLACK, 0.10)
    dark_ink = mix(WHITE, p, 0.08)
    dark_run = mix(run, WHITE, 0.35)
    dark = {
        "--bg": dark_bg,
        "--panel": dark_panel,
        "--panel-alt": mix(p, BLACK, 0.30),
        "--ink": dark_ink,
        "--muted": mix(WHITE, p, 0.40),
        "--accent": dark_ink,
        "--line": mix(p, WHITE, 0.14),
        "--chip": mix(p, BLACK, 0.20),
        "--chip-border": mix(p, WHITE, 0.20),
        "--header-bg": mix(p, BLACK, 0.20),
        "--header-border": rgba(WHITE, 0.12),
        "--header-link": dark_ink,
        "--header-link-muted": mix(dark_ink, p, 0.30),
        "--btn-bg": mix(p, WHITE, 0.15),
        "--btn-text": dark_ink,
        "--btn-border": mix(p, WHITE, 0.30),
        "--accent-fill": a,
        "--accent-ink": accent_ink,
        "--running": dark_run,
        "--running-soft": rgba(dark_run, 0.10),
        "--running-fill": rgba(dark_run, 0.22),
        "--sage": mix(preset.sage, dark_panel, 0.80),
        "--sage-ink": mix(preset.sage, WHITE, 0.30),
    }
    return {"light": light, "dark": dark}


@dataclass(frozen=True)
class ContrastWarning:
    key: str
    ratio: float
    minimum: float


def check_contrast(base: BaseColors) -> list[ContrastWarning]:
    checks = [
        ("background", contrast_ratio(base.primary, base.background), 4.5),
        ("accent", contrast_ratio(best_ink(base.accent, base.primary), base.accent), 4.5),
        ("primary", contrast_ratio(best_ink(base.primary, "#f6f7ff"), base.primary), 4.5),
        ("running", contrast_ratio(base.running, base.background), 3.0),
    ]
    return [ContrastWarning(key, round(ratio, 2), minimum) for key, ratio, minimum in checks if ratio < minimum]


def render_css(tokens: dict[str, dict[str, str]]) -> str:
    def block(values: dict[str, str]) -> str:
        return "".join(f"{k}:{v};" for k, v in values.items())

    return f':root{{{block(tokens["light"])}}}html[data-theme="dark"]{{{block(tokens["dark"])}}}'
```

def active_theme() -> tuple[theme.Preset, theme.BaseColors]:
    stored = db.get_settings_dict("theme_")
    overrides = {key: stored.get(f"theme_{key}", "") for key in theme.BASE_KEYS}
    return theme.resolve(stored.get("theme_preset"), overrides)


def theme_css() -> str:
    """Inline CSS for a non-default theme; '' when the stylesheet defaults apply."""
    try:
        stored = db.get_settings_dict("theme_")
        if not any(stored.values()):
            return ""
        preset, base = active_theme()
        return theme.render_css(theme.derive_tokens(preset, base))
    except Exception as exc:
        logger.warning("Theme rendering failed, using stylesheet defaults: %s", exc)
        return ""
